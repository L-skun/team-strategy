# 团队赛 Ban/Pick 策略工具

这是一个可直接在浏览器中使用的静态工具。输入双方卡组和对阵胜率后，它会给出最多 5 个推荐 Ban，并列出我方每套卡组被 Ban 时应选择的三套出战卡组。

## 实际操作

1. 首次打开时，页面会载入随机示例数据，方便体验完整流程。这些数字没有实战依据，正式计算前请替换为自己的胜率。
2. 从卡组池中分别选择我方和对手的出战候选，每方必须选择 4 至 6 套。内置对手池提供 22 套常见卡组；也可以临时添加其他对手卡组，并补全它与所选我方卡组的胜率。
3. 在“我方视角”表格填写对阵胜率。输入 `0.5`、`50%` 或 `50` 均表示 50%。我方视角存在空白或无效值时会阻止计算。
4. “对手视角”表格可以留空。空白格会自动采用“我方败率 + 信心补正”，最高不超过 100%；也可逐格填写对手的主观胜率覆盖自动值。
5. 选择同时暗排或随机配对，再选择稳健或预测模式，点击“计算推荐策略”查看最多 5 个推荐 Ban，以及我方每一种被 Ban 情况下的出战方案。

页面中的“保存到本机”只保存在当前浏览器，不会上传或云同步。需要换电脑、换手机或备份时，请导出 JSON 文件，再在另一台设备导入。

### Excel 导入

- 第一页是我方视角胜率：第一列从第二行起为我方卡组，第一行从第二列起为对手卡组，交叉单元格为我方胜率。
- 第二页可填写对手视角胜率。它可以沿用第一页的行列方向，也可以转置；两边的卡组名称必须能够与第一页匹配，工具才会正确对齐。
- 胜率支持 `0.5`、`50%` 和 `50` 三种写法。对手视角空白会自动补正，我方视角空白会阻止计算。

### 本地打开

直接打开 `dist/index.html` 即可使用。若浏览器限制本地文件读取，可在本目录运行：

```text
node serve.cjs
```

随后访问 `http://127.0.0.1:4173`。该预览服务只监听本机地址，并且只提供 `dist` 目录中的文件。

运行引擎测试：

```text
node --test tests/engine.test.cjs
```

## 模型说明

- 每方先 Ban 对手一套卡组，再从剩余卡组中选择三套；被 Ban 的卡组不会出战，同一卡组不会重复出战。
- 每场 BO1 相互独立。三场中至少赢两场的概率为 `xy + xz + yz - 2xyz`。
- “同时暗排”将三套卡组的出战顺序作为策略；“随机配对”对六种一一配对等概率取平均。
- 稳健模式选择最坏对手安排下胜率最高的我方纯策略，并按对手最不利的 Ban 计算保障胜率。
- 预测模式假定对手在每个决策阶段，都选择让其主观“最坏情况下保障胜率”最大的纯策略；多个同分最优选择按相同概率处理，再计算我方最佳应对。
- 该工具计算纯策略 maximin 或预测模型，不计算混合策略纳什均衡。
- 对手视角胜率为空时，使用 `clip(1 - 我方胜率 + 信心补正, 0, 1)`；显式填写的 `0` 会保留为 0。默认信心补正为 0.2。

## 引擎接口

浏览器中调用 `window.StrategyEngine.solve(input)`；CommonJS 中调用 `require('./dist/engine.js').solve(input)`。

`input` 包含我方视角胜率矩阵 `rates`，以及可选的 `opponentRates`、`correction`、双方名称、配对方式 `ordered | random` 和模式 `robust | predictive`。双方卡组数量分别必须为 4 到 6，胜率必须在 0 到 1 之间。求解器不会修改传入的数据。

结果中的索引都对应原始矩阵索引。`strategies` 按得分降序排列，每项包含 Ban 对手卡组的索引以及我方每一种被 Ban 情况的完整应对。预测模式还返回对手 Ban 我方各卡组的概率；稳健模式不假设概率分布，因此该数组为空。
