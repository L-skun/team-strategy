## 填写和计算

1. 双方各选择 4–6 套公开卡组。可点击对手区“全部取消选择”重新选择；展开“管理卡组池”可新增、重命名和删除双方卡组，并补全新增卡组的胜率。
2. 网页“我方视角”输入框按百分比填写：`50` 表示 50%，`0.5` 表示 0.5%。所有已选公开卡组的我方胜率必须完整填写。
3. “对手视角”可以留空，默认采用 `clip(1 - 我方胜率 + 信心补正, 0, 1)`；显式填写的 0 会保留。初始补正 20%。
4. 我方可勾选“我不想上”，这些卡组不会实际出战；对手仍按完整公开阵容决定 Ban 和排阵，也可能 Ban 被标记的卡组。排除后至少保留 4 套。
5. 选择同时暗排或随机配对、主观预测或稳健保障、推荐数量前 N 个或“全部”，点击计算。
6. 推荐按 Ban 对手卡组排名，每个被禁分支显示胜率最高的第 1～3 选；不足三个方案则展示全部。前三选按三套卡组的组合去重，同一组合只保留模型胜率最高的顺序；暗排仍在计算中比较不同顺序。只有一种合法组合时仅显示第 1 选。Ban 总分按各分支第 1 选计算。

## 胜率复位与整行/整列调整

“对手视角”每个格子下方有“复位”按钮，可清除该场手动值并恢复自动补正。自动格子的复位按钮为禁用状态。上方“全部复位为自动补正”会清空整个对手胜率池的手动值（包括未选卡组），不修改我方胜率。复位实际保存为空值，后续随我方胜率和信心补正变化；保存 Excel 后也为空白，不固定为某个估算数字。

展开“整行 / 整列批量调整胜率”，选择范围、方向、卡组与调整方式后点击应用：

- 统一设为固定胜率：输入 50，整行/列设为 50%，可以填充空白。
- 增减固定百分点：输入 10，50% → 60%；输入 -10，50% → 40%。
- 按原胜率比例增减：输入 10，50% → 55%；输入 -10，50% → 45%。比例减少最低 -100%。

结果限制在 0–100%。增减时无原始胜率的格子跳过并提示数量。对手自动格按当前补正值调整，之后转为手动值，可再复位。默认只操作当前表格中的对局，也可明确选择全部卡组池。行列以当前视角显示方向为准：对手视角行是对手卡组，列是我方卡组。批量操作自动保存并清除旧计算结果；不会自动写 Excel，需另外点击“保存 Excel”。PC、APK 与单文件手机版行为一致。

## 保存胜率和默认设置

胜率、双方卡组选择、临时卡组、“我不想上”、推荐数量、信心补正、策略模式及配对方式修改后自动保存。也可点击“保存胜率和默认设置”立即保存，等待页面出现“已保存”再关闭。无效胜率需要修正后才能保存。

初始默认前 5 个、信心补正 20%；调整一次后，下次以保存值为默认，不必重新调整。

EXE 模式保存到 `team-strategy/.local/state.json`，浏览器中另有备份。清除浏览器数据或换浏览器后，也能从项目文件恢复。数据仅保存在本机，不上传或云同步。导出 JSON 可额外备份；也可复制整个项目文件夹迁移。

## Excel 锚定与导入

### 示例 Excel 与快速上手

示例请使用 v1.1.2 或更新版本导入，已修复带 XML 命名空间前缀的标准 XLSX 兼容问题。

[下载胜率填写示例](examples/团队赛胜率填写示例.xlsx?raw=1) · [Release 附件下载](https://github.com/L-skun/team-strategy/releases/download/v1.1.2/matchup-example.xlsx)。Windows 完整 ZIP 中也附带该示例。

示例有三页，卡组与胜率全部为虚构数据，只用于练习填写及导入：

| 页序 | 内容 | 填写要求 |
| --- | --- | --- |
| 第一页“我方胜率（示例）” | 我方击败对手的胜率 | A2 向下为我方卡组，B1 向右为对手卡组；被选中的对局计算前必须填完 |
| 第二页“对手胜率（可留空）” | 对手主观认为自己击败我方的胜率 | 本示例已转置：A2 向下为对手卡组，B1 向右为我方卡组；名称须与第一页对应 |
| 第三页“填写说明” | 填写步骤、格式对照、自动补正计算示范 | 工具不导入该页，请保持它位于第三页 |

第一页布局举例：

| 我方 / 对手 | 示例对手甲 | 示例对手乙 |
| --- | --- | --- |
| 示例我方A | 50% | 60% |
| 示例我方B | 40% | 50% |

“示例我方A × 示例对手乙”的 60%，表示我方 A 击败对手乙的概率。第二页对应的是“对手乙 × 我方 A”，填的是对手的主观胜率，两者不要求互补。该格留空时，按默认补正估算为 100% − 60% + 20% = 60%。

1. 下载示例，修改两页中的卡组名称，保证名称不空白、不重复且相互对应。
2. 在第一页填入你的胜率；第二页不确定时保留空白。不要用 0 代替未知胜率。
3. 保存后，在 PC 或 App 点击“导入 Excel”。计算时双方各选 4–6 套卡组。
4. 想自动锚定时，将填写后的副本改名为“团队赛卡组对局分析.xlsx”，放到 EXE 同目录；不要覆盖尚未备份的实战文件。

### 胜率格式怎么填

**推荐统一输入带百分号的胜率，例如 50%、65.5%、0%、100%。** 示例中的胜率格已预设百分比显示；下表中的“常规数值”指单元格底层存储的数字。Excel 显示格式和录入方式会影响存储值，不确定时使用显式百分号。

| Excel 中的内容 | 导入后含义 | 注意 |
| --- | --- | --- |
| 50% | 50% | 推荐写法 |
| 常规数值 0.5 | 50% | 0–1 的数值按概率理解 |
| 常规数值 50 | 50% | 大于 1 的数值除以 100 后理解 |
| 常规数值 1 | 100% | 表示 1% 时请填 1%，不要填普通数字 1 |
| 1% | 1% | 低胜率也建议显式加百分号 |
| 0.5% | 0.5% | 不等于常规数值 0.5 所表示的 50% |
| 0 或 0% | 0% | 明确的零胜率，不是“未知” |
| 第一页留空 | 胜率缺失 | 可先导入，所选对局需补全后才能计算 |
| 第二页留空 | 自动补正 | 使用我方败率 + 当前信心补正，最高 100% |

**网页/App 输入框与 Excel 常规数值不同：输入框已带 % 单位，填 50 就是 50%，填 0.5 就是 0.5%。** 在网页/App 中填写 50% 的胜率应输入数字 50。

- 胜率应在 0%–100% 之间，不要填写比分、横线、“未知”或“自动”等文字。
- 第一页和第二页从 A1 开始放标题与胜率矩阵，不要加空白标题行、合并单元格、备注行或说明列；说明文字请放到第三页。
- 添加卡组可扩展矩阵，名字不要重复；先保持行列关系清晰，再导入策略台选择本场阵容。
- 需要自动补正的格子保留为空，不要把示范计算公式复制进第二页。示例第三页的公式只用于解释，不会导入策略台。

### 自动锚定规则

锚定文件为 EXE 同目录的 `团队赛卡组对局分析.xlsx`。每次打开或刷新页面都检查文件内容：

- 没有保存记录，或 Excel 内容变更：读取最新卡组及胜率，保留仍有效的界面设置。
- Excel 内容未变：恢复控制台保存的胜率及默认设置，保留网页上的修改。
- 点击“重新读取 Excel（覆盖界面胜率）”：主动以 Excel 覆盖界面卡组和胜率，保留仍有效设置。
- 文件缺失、格式错误或读取超时：显示原因，保留本机保存或示例数据。

网页修改默认保存在本地 JSON；点击“保存 Excel”才会写入表格。Excel 空白胜率保持空白，不自动填随机值。已删除的卡组会从选择中移除，剩余选择不足 4 套时默认选择新池前 6 套；排除后不足 4 套时清空“我不想上”。

Excel 格式：

- 第一页 A2 起向下为我方卡组，B1 起向右为对手卡组，交叉位置填我方胜率。
- 第二页可填对手视角胜率，支持沿用第一页方向或转置，名称需与第一页匹配。
- Excel 支持 `0.5`、`50%`、`50` 均表示 50%。
- 也可使用界面的“导入 Excel”手动导入其他文件，并自动保存到控制台。

## 将界面修改保存到 Excel

在“保存卡组和胜率到 Excel”区选择：

- **另存为新 Excel**：在锚定文件同目录生成带时间戳的新文件，不改变原锚定文件。
- **覆盖锚定 Excel**：先备份原文件到 `team-strategy/.local/excel-backups/`，再覆盖。原文件在外部更新时拒绝覆盖，需重新读取或另存；被 Excel 占用时会提示关闭文件后重试。

保存的是整个卡组池和全部双方视角胜率，包括未选择及“我不想上”的卡组。空白保持空白，对手自动补正值不当作显式输入写入。输出重建“我方视角”“对手视角”两张标准表，不保留原文件其他工作表、公式、自定义格式；原文件备份可完整恢复。默认设置继续单独保存在 JSON。直接 HTML 模式仅可下载新 Excel。

覆盖后更新文件版本，下次启动不会把旧界面数据当作新 Excel 覆盖。完整卡组池允许每方 1–100 套，计算时仍需各选 4–6 套。

## 模型及引擎接口

每方先 Ban 对手一套，再从剩余卡组选三套；每套只出战一次。三场 BO1 独立，至少赢两场的概率为 `xy + xz + yz - 2xyz`。同时暗排按顺序配对，随机配对平均六种一一配对。

稳健模式计算纯策略 maximin，选择最坏对手排阵下胜率最高的方案，再按对手最不利的 Ban 算总分。主观预测模式假设对手在每个决策阶段最大化其主观最坏情况下的保障胜率，并在同分选择间均匀分配；我方据此求最佳应对。不计算混合策略纳什均衡。

浏览器调用 `window.StrategyEngine.solve(input)`；CommonJS 调用 `require('./dist/engine.js').solve(input)`。

输入为我方胜率 `rates`（4–6 行、4–6 列），可选 `opponentRates`、`correction`（默认 0.2）、`ourNames`、`opponentNames`、`pairing`（`ordered | random`）、`mode`（`robust | predictive`）、`topN`（1–6 或 `all`，默认 5，实际数量不超过对手卡组数）、`excludedOurIndices`（不重复索引，排除后至少剩 4 套）。求解器不修改输入。

结果 `strategies` 按总分降序排列，索引对应原矩阵。每个 `branches` 分支包含至多三个不同卡组组合、按胜率降序的 `options`，每项有 `ourOrder`、`score`，稳健模式还有 `worstOpponentOrder`。原分支字段代表第 1 选，兼容旧接口。预测模式返回对手 Ban 概率及各分支公开阵容下的预测排阵，适用于该分支全部备选方案；稳健模式不假设 Ban 概率。旧 JSON 缺少新增设置时使用默认值。

胜率编辑回归检查：配置 Playwright 后运行 `node tests/rate-editor-smoke.cjs`，验证 PC、单文件手机版及原生桥接下的单场/全部复位、批量调整、空值保存和重新打开。
